这是公务员考试资料分析里的**分数比较速算技巧**（分数拆分法 / 分母拆分法），用来快速判断两个分数谁大谁小，比差分法、直除法更省时间。

> 全文公式已改为纯文本写法（如 907/936），不用渲染插件也能直接读。

---

## 一、原理：一句话总结

**把一个分数拆成「(大) / (小) + 1」的形式，就变成了比较「大 ÷ 小」这个比值——比值越大，原分数越大。**

### 1. 核心恒等式

设 a、b 都为正数（b > a），则

```
a / b  =  (a/(b-a)) / (a/(b-a) + 1)  =  x / (x+1)      其中 x = a/(b-a)
```

比如 907/936 = (907/29) / (907/29 + 1) = 31.28 / 32.28。

### 2. 为什么能这样比

函数 f(x) = x / (x+1) 在 x > 0 时**严格递增**：
x 越大，那个“+1”占的比例越小，f(x) 就越贴近 1。

所以：

```
a/b  >  c/d    ⇔    a/(b-a)  >  c/(d-c)
a/b  <  c/d    ⇔    a/(b-a)  <  c/(d-c)
```

**比较方向完全同向，不用反过来。**（这是最容易记错、也最容易被原文“反推”二字误导的一点。）

### 3. 直觉理解：看“离 1 有多近”

- 907/936 的缺口是 29/936，191/208 的缺口是 17/208。
- 缺口越小，分数越接近 1，也就越大。
- 拆分法就是把这个“缺口”和分子放在一起比：**分子 ÷ 缺口**，越大越接近 1。
  - 907/29 ≈ 31（缺口只占分子的 1/31）
  - 191/17 ≈ 11（缺口占分子的 1/11）
  - 缺口占比更小 → 907/936 更大。

一句话：**分子相比缺口越大，分数越大。**

### 4. 为什么比直除法快

- 拆分后的分母是“缺口”，常常只有两位数（29、17、44…），
  只需判断“一个数除以两位数，够不够另一个数”，一般心算就能出结果。
- 原分数越接近 1（两个数的差很小），缺口就越小，拆分法反而越好用——
  这正好补上直除法“数字太接近、算不准”的短板。

### 5. 原文里的“分子拆分”是怎么回事

原文第 2 条：若 a > c，则把 a/b 写成 (a−b)/b、c/d 写成 (c−d)/d 再比较
（例 4 用的就是这一条：153/94 与 210/155，其实等价于 153/247 与 210/365 互换位置比）。
这是同一思想用在“大于 1 的分数”上：先减掉 1，变成「超额 / 分母」再比，
超额占比越大，原分数越大。
但**考试中极少用到**，记住“分母拆分”一种就够了。

### 6. 常见误区（必看）

1. **比较方向反了**：拆分后谁大，原分数就谁大，是同向，不是反向。
2. **两个分数各自拆自己的缺口才严格等价**：a/(b−a) 与 c/(d−c) 各自用自己的缺口，
   这正是拆分法的标准做法，不需要“减同一个数”（原文的表述容易让人误解）。
3. **拆分法本身不要求两个分数都小于 1 或都大于 1**，只要分子分母都为正；
   一个小于 1、一个大于 1 时直接就能看出来，不用拆。

---

## 二、操作步骤（考场上三步）

1. **扫一眼**：谁大于 1、谁接近谁，先粗判大致方向。
2. **算缺口**：两分数各自的缺口（分母 − 分子），得到 a/(缺口)。
3. **比商**：比较 a/(b−a) 与 c/(d−c)，哪个大，原分数就哪个大。

## 三、例题演示（已逐题验算）

### 例 1：比较 907/936 与 191/208

- 缺口：936−907 = 29，208−191 = 17
- 拆成：907/29 ≈ 31.3；191/17 ≈ 11.2
- 判断：31.3 > 11.2，同向。
- 结论：**907/936 > 191/208**
- 验算：0.9690 > 0.9183 ✓

### 例 2：比较 563/748 与 157/201

- 缺口：748−563 = 185，201−157 = 44
- 拆成：563/185 ≈ 3.04；157/44 ≈ 3.57
- 判断：3.04 < 3.57，同向。
- 结论：**563/748 < 157/201**
- 验算：0.7527 < 0.7811 ✓（确实很接近，拆分法在这里救了场，直除法容易算糊）

### 例 3：比较 234/366 与 574/844

- 缺口：366−234 = 132，844−574 = 270
- 拆成：234/132 ≈ 1.77；574/270 ≈ 2.13
- 判断：1.77 < 2.13，同向。
- 结论：**234/366 < 574/844**
- 验算：0.6393 < 0.6801 ✓

### 例 4（两数都 > 1）：比较 400/247 与 575/365

- 缺口：400−247 = 153，575−365 = 210
- 拆成：153/247 ≈ 0.62；210/365 ≈ 0.58

  （都大于 1 时，看的是“超过 1 的部分 ÷ 分母”，即超额占比，占比越大，原分数越大。
   原文写成 153/94 与 210/155，是把它倒过来比，结论等价。）
- 判断：0.62 > 0.58。
- 结论：**400/247 > 575/365**
- 验算：1.6194 > 1.5753 ✓

## 四、搭配使用建议

| 场景 | 首选方法 |
| --- | --- |
| 两个分数都接近 1，差距小 | **拆分法（看缺口占比）** |
| 两个分数都是一般大小、差距明显 | 直接估首位 / 截位直除 |
| 一个比 1 大、一个比 1 小 | 一眼看出，不用算 |
| 分子分母交叉递增（一大一小） | 同向变化判断 / 拆分法 |
| 保底 | 截位直除保留两位 |

**核心一句：比大小不是比谁算得快，而是比谁先看出“离 1 的距离”。**
