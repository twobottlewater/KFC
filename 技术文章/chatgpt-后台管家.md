# ChatGPT 后台管家使用指南

## 核心理念
把 ChatGPT 变成默默在后台工作的管家，无需整理、分类，专注于推动工作进展。

## 使用方法

### 第一步：给它一个身份
打开新的对话窗口（置顶备用），发送以下提示词：

```
你现在是我的后台业务管家。当我把邮件、消息、笔记、会议纪要或者各种想法粘贴给你时，你需要做以下几件事：

1. 清晰地总结每一项内容
2. 识别出哪些事情需要我采取行动或跟进
3. 建议一个简单的下一步操作
4. 标记出哪些事情可以稍后处理
5. 按紧急程度把事情分好类

请保持回复简短实用，专注于推动工作进展，不要给我写长篇大论的计划。
```

### 第二步：把杂乱扔给它
无需格式，无需整理，直接粘贴所有信息：
- 邮件
- 消息
- 笔记
- 会议纪要
- 灵感想法

把它当成垃圾桶，发完就不管，继续做手头的事。

### 第三步：像老板一样查岗
随时询问，让它帮你整理：

- "我现在最需要关注的事情是什么"
- "把所有事情变成一个行动清单发给我"
- "有哪些我可以快速回复的消息"
- "是什么在阻碍我的进度"

它会将杂乱信息变成清晰的执行指令。

### 第四步：周末清空大脑
周五或周末时，发送：

```
给我一份本周运营快照，包括取得了哪些进展，哪些事情停滞了，下周需要跟进什么，以及哪些事情可以归档了。
```

## 精髓
- 大脑擅长思考和创造，不适合存储琐碎信息
- 把"记住事情"外包给 AI，释放大脑能量
- 专注于当下，剩下的交给后台管家
- 最高级的效率，往往只需要最朴素的方式
