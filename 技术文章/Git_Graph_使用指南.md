# Git Graph 插件使用指南

## 一、基本功能与界面介绍

Git Graph 是 VS Code 中一款强大的 Git 可视化插件，用于直观展示分支结构、提交历史和合并关系。

### 1. 打开插件
- 方式1：点击左侧活动栏的 Git Graph 图标（蓝色分支图标）
- 方式2：使用快捷键 `Ctrl+Shift+P`，输入 "Git Graph: Show Git Graph" 并回车

### 2. 主界面元素
- **提交节点**：圆形节点代表提交，颜色区分不同分支
- **分支标签**：显示分支名称，当前分支有特殊标记
- **合并线**：箭头连线表示提交流向和合并关系
- **时间轴**：从下到上表示时间先后（最新提交在上）

## 二、分支关系与提交历史分析

### 1. 识别活跃分支
- 查看分支标签：活跃分支通常显示在节点右侧
- 分支颜色：不同分支使用不同颜色标识
- 当前分支：带有 "HEAD" 标记的分支

### 2. 查看分支创建来源
- 找到分支的第一个提交节点
- 查看该节点的父节点：父节点所在分支即为创建来源
- 右键点击分支标签 → 选择 "Branch Info" 可查看详细信息

### 3. 追踪提交记录流向
- 沿着节点连线向上/向下追踪
- 合并节点会显示多个入向箭头，表示来自不同分支的提交
- 右键点击节点 → "View Commit Details" 查看完整提交信息

### 4. 理解分支间合并关系
- 合并节点：菱形或特殊标记的节点
- 合并线：从各个分支指向合并节点的连线
- 右键点击合并节点 → "View Merge Details" 查看合并信息

## 三、对比任意两个节点的差异

### 对比步骤（以您提供的节点为例）

#### 方法1：直接在图中选择对比
1. **选择第一个节点**：
   - 右键点击节点 `a405fb702e8684fdcf46fcce7cb857a72ba16cc3`
   - 选择 "Compare with Commit..."

2. **选择第二个节点**：
   - 在弹出的提交列表中找到并选择 `0653512fcdd94b9c14c8f53524579461e65727d9`
   - 点击 "Compare"

3. **查看差异**：
   - VS Code 将在侧边栏打开差异对比视图
   - 左侧显示第一个节点的内容，右侧显示第二个节点的内容
   - 红色表示删除，绿色表示添加

#### 方法2：使用命令面板
1. 按下 `Ctrl+Shift+P`
2. 输入 "Git Graph: Compare Two Commits"
3. 依次输入两个提交的哈希值（可复制粘贴）
4. 按回车后查看差异

#### 方法3：拖拽对比
- 在 Git Graph 视图中，按住 `Ctrl` 键
- 同时点击两个要对比的节点
- 右键点击其中一个 → 选择 "Compare Selected Commits"

## 四、高级功能

### 1. 筛选与搜索
- 使用顶部搜索框查找特定提交（按哈希值、作者、提交信息）
- 点击 "Filters" 按钮筛选特定分支、作者或时间段

### 2. 分支管理
- 右键点击分支 → 可执行 checkout、merge、rebase、delete 等操作
- 拖拽分支标签可快速切换分支

### 3. 提交操作
- 右键点击提交 → 可创建分支、标签，或重置当前分支到该提交
- 双击提交可查看完整的提交文件列表

## 五、实用技巧

### 1. 调整视图
- 点击 "Layout" 按钮切换不同的布局样式（垂直、水平、紧凑等）
- 使用 "Zoom" 控制视图缩放比例

### 2. 快捷键
- `Ctrl+Shift+P` → "Git Graph"：快速访问所有功能
- `Alt+G Alt+G`：快速打开 Git Graph 视图

### 3. 自定义设置
- 在 VS Code 设置中搜索 "Git Graph" 可调整插件行为
- 可自定义分支颜色、节点样式等

---

通过以上操作，您可以高效地使用 Git Graph 插件分析分支结构、查看提交历史，并精确对比任意两个节点之间的差异。
