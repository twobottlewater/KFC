# Markdown 常用语法速查

> 结合你的写作习惯整理的简易笔记，主打实用高效。

---

## 1. 标题层级 (常用)
用来构建文章骨架，建议最多用到三级或四级。

```markdown
# 一级标题 (文章大标题)
## 二级标题 (大章节)
### 三级标题 (子要点)
#### 四级标题 (细节)
```

## 2. 强调与重点
申论/笔记积累中常用，用于突出核心观点或金句。

- **加粗**：`**核心观点**` → **核心观点** (最常用)
- *斜体*：`*斜体*` → *斜体* (较少用)
- 标注：\``代码/关键词`\` → `关键词` (用于强调短语)

## 3. 列表整理
用于梳理逻辑、分点论述。

**无序列表 (最常用)：**
```markdown
- 观点一
- 观点二
  - 子观点 (缩进2个空格)
```

**有序列表：**
```markdown
1. 第一点
2. 第二点
```

## 4. 引用与金句
用于摘录名言、习近平总书记语录。

```markdown
> "艰难方显勇毅，磨砺始得玉成。"
> —— 摘录来源
```
> 效果展示："艰难方显勇毅，磨砺始得玉成。"

## 5. 图片插入
你的自动粘贴配置已生效，直接粘贴即可。

```markdown
![图片描述](./assets/image-日期.png)
```
*提示：使用 `Ctrl + Alt + V` 可自动保存到 assets 文件夹*

## 6. 分割线
用于区分不同的大板块内容。

```markdown
---
```

## 7. 链接 (可选)
```markdown
[点击跳转到某处](链接地址)
```

---
**小技巧**：
- 换行：Markdown 中直接回车可能不换行，建议**空一行**来分段。
- 粘贴图片：推荐始终使用配置好的快捷键，保持文件夹整洁。
