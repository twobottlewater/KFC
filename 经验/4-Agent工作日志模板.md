# Agent 工作日志模板（模块通用）

> 用途：让接手任意模块的 AI，按同一套流程整理学习文档。
> 用法：复制本文件到模块目录并改名为 `agent日志.md`，把 `{}` 占位内容替换为该模块的实际情况，然后让 AI 先读它再操作。参考实例：`图推/agent日志.md`。

## 一、工作模式

- 用户负责写入：学习时随手把笔记、截图贴进文档（习惯贴在文末，裸贴）
- AI 负责整理：核对内容 → 判断是否与已有章节重复 → 归类 / 开新节 → 提炼要点 → 标注来源 → 全量校验图片链接
- 大改动前先给"目标 + 方案"，用户确认后执行

## 二、维护范围（硬性规则）

- 只整理 `{模块名}/` 这一个目录，不碰仓库其他部分
- 只维护以下文件：
  - `{主文档}.md` —— 课程考点主文档
  - `{题目记录}.md` —— 具体题目记录（暂无题录可只列主文档）
- 固定区块：{哪些内容严禁移动 / 替换 / 删除，如头图}

## 三、文档规范

- 图片统一放 `{模块名}/images/`，md 内用相对路径 `images/xxx.png` 引用（不用 `../images/`）
- 图片命名：`image-YYYYMMDDHHMMSS.png`（时间戳）
- 每个章节标注来源（老师名 / 课程名 / 真题年份 + 题号）
- 去重规则：与已有章节重复的内容合并去重，图片文件留磁盘不删
- 整理完成后必须全量校验图片引用，确保零死链
- 不要在图片 URL 后加 fragment；不用 `style=` 控宽（GitHub 会剥离）
