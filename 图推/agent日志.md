# 图推 · Agent 工作日志

> 本文件由用户维护，是 AI 整理 `图推/` 目录的操作依据。
> 任何接手的 Agent：先通读本文件，再动手；用户说"按照 agent日志 操作"时，以本文件为准。

## 一、工作模式

- 用户负责写入：看课、做题时随手把笔记和截图贴进文档（习惯贴在文末，裸贴）
- AI 负责整理：核对内容 → 判断是否与已有章节重复 → 归类 / 开新节 → 提炼要点 → 标注来源 → 全量校验图片链接
- 大改动前先给"目标 + 方案"，用户确认后执行

## 二、维护范围（硬性规则）

- 只整理 `图推/` 这一个目录，不碰仓库其他部分
- 只维护两份文件：
  - `图形推理学习.md` —— 课程考点主文档（2026-10-15 由 `图形推理题目.md` 改名而来）
  - `题目记录.md` —— 具体题目记录
- `图形推理学习.md` 头图为固定内容，严禁移动、替换、删除；其余正文可自由增删调整

## 三、文档规范

- 图片统一放 `图推/images/`，md 内用相对路径 `images/xxx.png` 引用（不用 `../images/`）
- 图片命名（2026-10-19 起）：`编号号-考点-来源或关键词.png`，如 `09号-内外分开看16宫格-超格刘义恒.jpg`；旧的时间戳名已批量改完
- 图片索引：`.workbuddy-ai/notes/图片索引.md`（每张图的文本替身），整理笔记先读索引、不再逐张看图；`state.json` 记编号游标
- 每个章节标注来源，如：超格刘义恒《图推命题思维》、图推700题 · 超格刘义恒（23联考第2题）
- 去重规则：与已有章节重复的内容合并去重；重复图移入 `.workbuddy-ai/notes/回收站/`，编号留空不复用
- 整理完成后必须全量校验图片引用，确保零死链（脚本：`~/.workbuddy-ai/skills/md-note-organizer/scripts/check.py`）
- 头图两张为锚点图，文件名锁定，不改名不移动
